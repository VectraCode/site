Ritera

Privacy Policy

This policy describes the current Ritera app behavior. Ritera is a habit tracker designed to work without an account.

Last updated: September 21, 2026 Brand: VectraCode Publisher / legal contact: Kurushin Viktor Contact: support@vectracode.net Public policy URL: https://vectracode.net/ritera/privacy

Overview

Ritera is built for local habit tracking. The current version stores habit data on the user's device and does not include cloud sync, advertising, or in-app analytics.

Data Stored On The Device

Ritera stores the following data locally:

  • habit names;
  • habit frequency and custom interval settings;
  • habit color and icon choices;
  • habit creation dates;
  • completed habit dates;
  • reminder settings, such as enabled state and reminder time;
  • app settings, such as theme preference.

This data is stored locally by the app so the user can track habits and see progress over time.

Backups, Import, And Export

When the user exports data, Ritera creates a backup file on the device and uses the system share or save flow. The user chooses where that file is saved or sent.

When the user imports data, Ritera reads only the backup file selected by the user. Imported habits are added to the existing list and do not replace current habits unless the user separately deletes data.

Notifications

If the user enables reminders, Ritera schedules local notifications on the device. Reminder scheduling is used only to show habit reminders. On Android, the app may ask for notification permission and may use system startup events to keep scheduled reminders available after the device restarts.

Data Sharing

Ritera does not sell personal data, does not show ads, and does not send habit data to a Ritera server.

Habit data may leave the device only when the user chooses to export or share a backup file through the system share or save flow.

Purchases

Ritera Pro is available as a one-time purchase. On Android, purchases are processed by Google Play according to Google's terms and privacy practices. Ritera receives the purchase status needed to unlock or restore Pro features but does not receive or store the user's payment card details.

Data Deletion

The app includes an option to delete all local habit data, completion history, and local reminder settings from the device. Users can also remove the app from the device to delete app data according to the operating system behavior.

Children's Privacy

Ritera is not designed to collect personal information from children. The current version does not include accounts, social features, advertising, or analytics.

Changes

This policy may be updated when Ritera adds new features, such as sync, analytics, or account-based functionality. Material changes should be reflected in this document before release.
